# Domain glossary

## Leader key

A keyboard shortcut that opens or closes the switcher.

## Default leader key

The leader key used when no keyboard override applies.

## Keyboard override

A rule that selects a different leader key while its keyboard is connected.

## Effective leader key

The leader key that is currently active. It is either the default leader key or the leader key from the highest-priority connected keyboard override.

## Keyboard identity

The saved hardware identity used to recognize a keyboard after it reconnects.

## Connected keyboard

A keyboard that macOS currently reports as attached and available.
